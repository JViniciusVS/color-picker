# 🎨 Color Picker

Este é um projeto de **Color Picker** desenvolvido em **React**, permitindo ao usuário selecionar uma cor e visualizar a mudança em tempo real.

## 🛠 Tecnologias Utilizadas

- React.js  
- TypeScript (se aplicável)  
- Tailwind CSS (se aplicável)  

## 🎨 Funcionalidades

- Interface simples e intuitiva.  
- Seletor de cores integrado.  
- Atualização dinâmica da cor selecionada.  
- Exibição do código hexadecimal da cor escolhida.
